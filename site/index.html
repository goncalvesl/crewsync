Como funciona

Uma base comum para o trabalho de cada dia.

O servidor recebe as mudanças e organiza as revisões. Cada computador mantém sua pasta local e sincroniza somente os compartilhamentos permitidos.

01 / COMPARTILHAR

Escolha quem pode alterar.

Configure usuários e pastas no servidor. Acesso de leitura para consultar; escrita para criar, modificar e excluir. Novas permissões são aplicadas sem reiniciar. Adicionar pastas e usuários →

02 / SINCRONIZAR

Deixe a pasta acompanhar.

Escolha somente a raiz local. Cada pasta autorizada aparece dentro dela automaticamente, com eventos de arquivos e verificações periódicas.

03 / RECUPERAR

Volte a uma versão anterior.

Consulte o histórico e restaure arquivos como uma nova revisão. Alterações concorrentes ficam preservadas para resolver conflitos.

Simples de inspecionar

Um cliente direto.
Um servidor seu.

O piloto usa linha de comando e pode rodar como serviço Linux. A instalação por pacote dispensa Rust, Cargo e Python no computador do usuário.

Gere um convite para cada computador, mesmo quando vários pertencem ao mesmo usuário. Cada dispositivo recebe sua própria credencial e herda as permissões do usuário. Revogue um computador sem bloquear os demais.

Instalação e versões

Prepare seu ambiente.
Comece com um piloto.

Linux com kernel 5.6 ou superior. Debian/Fedora e tar.gz oferecem x86_64 e ARM64; o pacote Arch está disponível para x86_64.

Sem versão estável publicada. Windows, interface gráfica e Android estão no planejamento posterior.
